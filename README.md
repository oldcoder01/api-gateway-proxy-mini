# API Gateway Proxy Mini

Small AWS Serverless API using:

- API Gateway HTTP API
- AWS Lambda (Node.js)
- Basic internal router/controllers/services structure

## Endpoints (initial)

- `GET /status` – Returns service health/status information.
- `GET /items` – Returns placeholder items list.

Infra-as-code (SAM/Terraform/CDK) to be added later.
